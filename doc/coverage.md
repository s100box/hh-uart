## Hole triage

The remaining uncovered points in this eight-run baseline are fixed by source
constants or by invariants for the exercised configurations. Literal operands
and parameters account for the `uart16550` entries below. The
[formal coverage map](formal-coverage.md) records the core proof's exact
configurations, retained assertions, sampled negative controls and limits.
Per-line detail is in `sim/vl/build/cov/report/annotate_all/` (`%` uncovered,
`+` covered), or `python tools/cov_summary.py --holes` lists the points.

### (a) Dead by design, constant in the source

- **`uart16550` `int_vec_o[7:0]` never falls.** `assign int_vec_o =
  IRQ_VECTOR;` drives it from a parameter, so each instance's value is fixed
  at elaboration. The bench builds two values (`8'hFF` and `8'h3C`) and checks
  both on the port.
- **`uart16550` `to_threshold[1:0]`.** `{frame_bits, 2'h0}`: the character
  timeout is four frame times, a shift by two, so the low two bits are the
  literal zeros. `frame_bits` itself takes every value from 7 to 12 in the
  bench (5N1, 8N1, 8E2 timeouts among them) and toggles fully.
- **`uart16550` `iir_val[5:4]`.** `{fifo_status_bits, 2'b00, iir_code}`: IIR
  bits 5:4 read 0 on every 8250-family member, so they are a literal in the
  concatenation.

### (b) Dead by design, proved

- **`uart_baud_dds` accumulator bits 28-31 and the carry (`ref_acc_q[31:28]`,
  `ref_sum[32:28]`).** The core proof uses `CLK_HZ=200000000` and
  `REF_HZ=1843200`. It proves the accumulator below 200000000 and the listed
  upper bits zero; the sum is below 201843200, also below 2^28. This bounds
  the baseline's exercised configurations. It does not prove these bits
  constant for every legal `CLK_HZ`/`REF_HZ` elaboration.
- **The low five bits of the data masks (`uart_rx_core` `data_mask[4:0]`,
  `uart_tx_core` `dmask_load[4:0]`) never fall.** Proved constant `5'h1F`: a
  frame has at least five data bits (`word_len_i` 0 = 5), so
  `8'hFF >> (8 - ndata)` always has its low five bits set; only bits 5-7
  depend on the word length, and those toggle.
- **`usb_serial_if.rx_err`.** `usb_serial_chan` ties it to `2'b00` (USB-sourced
  bytes carry no wire framing errors), and it is the only `chan`-side driver in
  this repository. The interface itself has no logic; its toggle figures are
  those of the signals `usb_serial_chan` drives through it.

### (c) Unreachable from the ports, covered by fault injection

- **The `default` arm of each core's state case.** The state register is three
  bits, with five receiver states and four transmitter states. The core proof
  excludes RX codes 5-7 and TX codes 1, 5-7 through every input sequence; the arm
  exists so a corrupted state recovers to idle. `tb_uart_tx_core` and
  `tb_uart_rx_core` force the register to each unused code, check the
  arm returns the FSM to idle on the next tick with no strobe, and that the
  core then runs a clean frame. Line coverage is therefore 100% on both cores.
